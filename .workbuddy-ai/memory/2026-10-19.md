## YouTube-sys 项目梳理与本地启动

### 项目认知
- 业务：YouTube 内容生成与自动化后台。两大子系统：
  1. 关键词系统（第一期）：Suggest 拓长尾词 → SerpApi + YouTube Data API V3 取视频/频道数据 → 规则/AI 打分找内容空位（博彩垂类）。打分模型 1.0（前5规则）与 2.0（AI 博彩意图筛选+全量打分）。

### 架构 / 技术栈
- 后端 backend/：Django 5.2 + DRF + Celery + Redis；apps: keywords, content_gen；config/。Python 3.12(Docker)。
- 前端 frontend/：Vue3 + Vite6 + Element Plus，nginx 托管。
- 渲染 render/：Node22 + Remotion4 + Express(server.mjs, 内网:3000)。
- 编排 docker-compose：db(pg16) redis(7) backend(gunicorn:8000,仅127.0.0.1) worker(celery) render frontend(nginx:8080)。共享 media_data 卷。
- DB：有 POSTGRES_HOST 用 PG，否则回退 SQLite(settings.py)。
