- 关键词（KEYWORDS）：需要进行排名的目标关键词列表，搜索量从大到小（例如：1win promo code，promo code 1win，1win kaise，1win app，1win token，1win game，1win account）。列表第一个词为"主词"。

# 输出要求

依次输出三个部分：一、标题；二、视频描述；三、封面图提示词。

## 一、标题
- 提供 3 个标题版本，每个标题长度均需在 70 个字符以内。
- 将主词（KEYWORDS 列表第一个词）置于标题开头，并且必须包含一个其他的关键词（在1win kaise，1win app，1win token，1win game，1win account选择一个)。

- 采用编号列表输出。

## 二、视频描述（置于代码块内，方便一键复制）
- 开篇使用一行引人入胜的文案，包含主词及主要优势。

- 提供带时间戳的章节列表（从 0:00 的"简介"开始，并根据主题划分 4-5 个逻辑板块）。
- 设置清晰的行动号召（CTA）板块，包含优惠码（PROMO_CODE）和推广链接（AFFILIATE_LINK）。
- 添加标签（Hashtag）行：将每个关键词转换为 #驼峰命名法（camelCase）或无空格标签，与关键词数量一致。
- 重要：所有关键词必须包含在视频描述中！！！

## 三、封面图提示词（单段英文，置于代码块内，可一键复制）

输出一段连续的英文提示词，不使用表格或多层缩进，须依次覆盖：
1. 画幅与整体定位（如 16:9, clean corporate and official design, no people）

3. 背景：深色蓝调渐变 + 几何光效 + 克制金色粒子
4. 文字叠加：主词大字（白色无衬线）+ 优惠码（金色高亮框）
5. 配色与质感：蓝金品牌点缀、柔和影棚光、高对比、锐利、premium fintech 质感
