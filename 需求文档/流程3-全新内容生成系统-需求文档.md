# 流程3 · 全新内容生成系统 — 需求文档

> 版本：v1.0　｜　状态：待评审　｜　来源：Notion「3 全新内容生成系统—流程3」+ 需求方补充澄清  
> 本文档为开发实施依据。**流程3 与现有流程1/2 完全代码隔离**，后续流程1/2 会被删除，流程3 不得受影响。

---

## 0. 核心原则（最高优先级）

1. **代码完全隔离**：流程3 独立为新的 Django app（命名 `flow3`），**绝不复用、绝不改动** `content_gen`（流程1/2）的任何 models / services / tasks / views / serializers / urls。前端同理，独立页面与路由。
   - 删除流程1/2 时：直接删除 `content_gen` app、`render/src` 里流程1/2 的组件、前端流程1/2 页面即可，`flow3` 自成闭环不受牵连。
   - 允许「复制」流程1/2 的成熟代码到 flow3 内改造，但**不允许 import 跨 app 依赖**（底层 AI 调用除外，见下）。
2. **底层 AI 调用的唯一例外**：`keywords.services` 里的 `_call_ai_stream()` / `_extract_json()` / `get_setting()` 是全局基础能力（非流程1/2 专属），flow3 可继续依赖。若需彻底解耦，可在 flow3 内复制一份，二选一，开发时确认。
3. **单视频模式**：一个任务 = 一个关键词 = 一个成品视频。**流程3 不做批量**（无 video_count、无 CSV 批量 promo code）。
4. **全流程详细日志**：每一步的输入 prompt、AI 原始输出、解析结果、耗时、状态都要落库，供前端日志抽屉查看（沿用 gen_log / run_log 的设计，但代码写在 flow3 内）。
5. **系统不含文生视频能力**：Hook 视频由 AI 生成 Prompt 文本，人工拿去外部视频引擎生成后回传 mp4。系统本身不直接生成 Hook 视频。

---

## 1. 业务定位

流程3 产出**16:9 1080P 的三段式长视频**（最长 4 分钟），用于 YouTube 博彩/体育推广（1xBet 类），通过长视频维持播放权重、引导观众用 Promo Code 注册。

与流程1/2 的区别：流程1/2 是短视频（16s 单一画面模板）；流程3 是**三段异构拼接的长视频**，含画中画合成、尾图微动、BGM 混音、防封去重。

---

## 2. 成片结构：三段式（16:9 / 1920×1080 / 30fps）

| 段             | 时间                 | 画面                                                      | 生成机制                                                       |
| ------------- | ------------------ | ------------------------------------------------------- | ---------------------------------------------------------- |
| **Segment A** | 00:00–00:08（固定 8s） | 高吸引力动态 Hook 视频                                          | Hook 文案 Agent 出 Prompt → 人工外部生成 mp4 → 回传上传                 |
| **Segment B** | 00:08–TTS结束（动态）    | 左右分屏：左 Promo Code 静态大字+引导文案，右 9:16 手机注册录屏（画中画），底为高斯模糊底图 | Remotion 组件合成；语音 Agent 出文案 → 印式英语 TTS 配音；底图由「模糊底图 Agent」生图 |
| **Segment C** | SegB结束–总时长（动态）     | 静态高清尾图 + 呼吸感微幅缩放/抖动                                     | 尾图 Agent 出 Prompt → 调三方生图 API → ffmpeg zoompan 微动          |

**时长计算**：

- 总时长 = 任务创建时用户填写的值（如 240s）。
- SegA = 8s（固定）。
- SegB = TTS 旁白音频实际时长（从第 8s 开始；用 ffprobe 读音频时长）。
- SegC = 总时长 − 8 − SegB时长。（SegC 即「30s 后那段图片抖动」，其结束点 = 总时长）
- 约束校验：若 8 + SegB > 总时长，判定配置冲突，报错提示用户调大总时长或缩短旁白。

**合成技术路线（已拍板）**：

- SegB：**Remotion 画中画组件**（文字 + 录屏 + 高斯模糊底图易排版，左右位置由随机种子决定）。
- SegC：**ffmpeg zoompan** 做呼吸/抖动微动（避免 Remotion 逐帧渲 4min 过慢）。
- 三段合并：**ffmpeg concat**（统一编码/分辨率/帧率后拼接）。
- 最后：叠加 BGM 混音 + 防封去重微调。

## 3. 多 Agent 架构（流程3 专属，独立一组）

流程3 使用**全新独立的一组 Agent**，与流程1/2 的 ContentAgent 隔离（flow3 自己的 Agent 表）。在「内容生成 → Agent 管理」里为流程3 单独分组展示 UI。

| Agent                  | 职责与输入                                         | 输出与流向                                          |
| ---------------------- | --------------------------------------------- | ---------------------------------------------- |
| **Hook 视频文案 Agent**    | 接收国家/赛事等参数，生成高点击率的 8s Hook 视频 Prompt 文案       | 输出 Prompt 文本到系统界面（展示/可复制），供人工去外部视频引擎生成，再回传 mp4 |
| **语音文案 Agent（7s-30s）** | 生成针对 Promo Code 注册引导的口语化旁白文案                  | 文本 → 系统内部 TTS（印式英语发音）合成音频                      |
| **模糊底图 Agent**         | 生成 SegB 用的高质高斯模糊底图的生图 Prompt                  | 调三方生图 API → 返回图片作为 SegB 底图                     |
| **尾图 Agent**           | 生成 SegC 用的 Eye-catching 博彩/奢华/体育主题高清图片 Prompt | 调三方生图 API → 返回图片作为 SegC 尾图背景                   |
| **元数据 Agent**          | 根据任务关键词 `[input]` 生成 YouTube 标题 / 描述 / 封面提示词  | 生成 txt，与视频一起打包成 zip                            |

> 关键：模糊底图 Agent 与尾图 Agent 是**两个独立 Agent**，提示词完全不同，不得混用。  
> 三方 AI 平台 moretokens 的 apikey 与模型名已在「全局设置」配置，flow3 读取全局设置即可。

## 4. Agent 管理面板（Prompt Admin，流程3 独立分组）

可视化配置面板，运营可独立修改和测试每个 Agent 的 System Prompt。UI 与现有 Agent 管理保持一致风格，但数据与代码归属 flow3。

- **全局变量注入**：System Prompt 中支持动态占位符 `{PROMO_CODE}`、`{COUNTRY}`、`{EVENT_NAME}`（以及元数据的 `[input]` = 关键词）。
- **Hook Agent 配置**：可设定视频 Prompt 风格（如 3D 渲染、大奖氛围）。
- **语音 Agent 配置**：口音固定印式英语；语气/字数风格可配（语气通过文案风格体现）。
- **模糊底图 Agent 配置**：可配默认修饰词（如 8k, photorealistic, luxury theme, gaussian blur background），可一键测试触发生图 API。
- **尾图 Agent 配置**：可配默认修饰词（luxury/sports/betting theme 等），可一键测试触发生图 API。
- **元数据 Agent 配置**：`[input]` 为任务创建时用户填写的关键词。
- 每个 Agent 支持「恢复系统默认提示词」（flow3 内置默认）。

## 5. 素材库（流程3 全新独立模块）

与流程1/2 的模板 assets **完全不同、代码隔离**。新建 flow3 自己的素材库，支持增删改查。素材分两类，需明确区分：

| 素材类型          | 说明                 | 数量与取用                                          |
| ------------- | ------------------ | ---------------------------------------------- |
| **9:16 手机录屏** | SegB 右侧画中画用的注册演示录屏 | 库内固定维护 **1 个**（可替换），所有流程3任务**自动取用**该录屏         |
| **背景音乐（BGM）** | 全局混入成片的背景音乐        | 库内**批量上传多个**，任务执行时**随机抽取 1 个**（随机种子记录到任务，便于复现） |

> Hook 视频**不进素材库**——它是每个任务单独上传的（见工作流 Step 3）。  
> 素材库 UI 需对两类素材分区展示与管理。

## 6. 全流程工作流（Workflow）

> 全程详细日志落库。单视频、无批量。

**Step 1 · 任务创建**  
在「内容生成 → 任务管理」创建任务，选择「流程三」，填写：

- 关键词（**仅支持 1 个**，后续传给元数据 Agent 的 `[input]`）
- 总时长（秒，如 240；决定 SegC 结束点）
- Promo Code（手填，如 `ZH567`）
- 国家 / 赛事名（EVENT_NAME 等，注入 Agent 占位符）
- 语言（旁白语言，默认印式英语）

**Step 2 · Hook Prompt 生成**  
Hook 文案 Agent → 生成 Hook 视频 Prompt 文本，展示在界面供复制。

**Step 3 · 暂停等待 Hook 上传**  
任务进入**暂停态**（等待人工介入）。人工拿 Step2 的 Prompt 去外部视频引擎生成 Hook mp4，回到系统**上传该 mp4**（单个任务只上传 1 条 Hook 视频）。上传完成后手动「继续」触发后续。

**Step 4 · Agent 并行计算**（Hook mp4 上传后）  
并行执行：

- 语音文案 Agent → 生成旁白脚本 → 触发系统 TTS（印式英语）合成音频。
- 模糊底图 Agent → 生成底图 Prompt → 自动调三方生图 API → 得 SegB 高斯模糊底图。
- 尾图 Agent → 生成尾图 Prompt → 自动调三方生图 API → 得 SegC 尾图。
- 元数据 Agent → 生成标题 / 描述 / 封面提示词。

**Step 5 · 图层与媒体组装**

- 按 TTS 音频实际时长确定 SegB 段长（从第 7s 起）。
- **SegB 画中画合成（Remotion）**：9:16 录屏 + Promo Code 静态大字（左或右）+ 引导文案 + 高斯模糊底图置底。**录屏与 Promo Code 的左右位置按随机种子决定**（本视频录屏在右则文字在左，反之亦然；种子记录到任务）。
- **SegC 微动（ffmpeg zoompan）**：尾图应用呼吸/抖动微幅缩放，持续到总时长结束。
- **三段 concat**：SegA(Hook mp4) + SegB + SegC 按序合并，统一编码/分辨率/帧率。

**Step 6 · 混音与防封去重**

- 叠加全局 BGM（从 BGM 库随机抽 1 个，种子记录），调整音频增益混音。
- 防封去重：对最终视频施加像素级色彩/尺寸微调（亮度/对比度/缩放 1~2% 级），使每条输出的文件哈希不同。
  > 注：防封暂无严格标准，先按此实现一版跑通流程，后续再优化。

**Step 7 · 交付打包**  
元数据 Agent 产出的 txt（标题/描述/封面提示词）+ 封面图 + 成品视频，打包成 zip 供下载。人工在 AdsPower 手动上传。

> flow3 **自己独立实现** zip 打包接口，**不复用** `content_gen` 的 package，避免删除流程1/2 时连带删除。

## 8. 后端实现要点（flow3 app）

**新建 Django app：`flow3`**，建议结构：

```
backend/flow3/
  models.py        # Flow3Run, Flow3Agent, Flow3Material（录屏/BGM）
  services.py      # 旁白生成、双生图、印式TTS、画中画调度、zoompan、concat、BGM混音、防封、zip
  tasks.py         # Celery：process_flow3_run（含 Step2 出prompt→暂停；Step4~7 续跑）
  views.py         # 任务CRUD、Hook上传、继续、素材库CRUD、Agent管理、打包下载
  serializers.py
  urls.py
  migrations/      # 独立迁移 + Agent 种子
```

**数据模型要点**

- `Flow3Run`：关键词、总时长、promo_code、country、event_name、language、status（新增中间态 `awaiting_hook`）、layout_seed（左右随机种子）、bgm_seed、run_log、task_token、hook_prompt、hook_video（上传的 mp4）、各生图/音频/成品文件、gen_log。
- `Flow3Agent`：agent_type（hook / narration / blur_bg / tail_image / metadata）、name、prompt、enabled。
- `Flow3Material`：type（`screen_record` / `bgm`）、file、name、enabled。

**状态机（关键新增）**

```
pending → running(出Hook prompt) → awaiting_hook(暂停等上传)
  → [人工上传mp4 + 点继续] → running(Step4~7) → completed / failed
  （任意阶段可 pause/stop/restart）
```

**印式英语 TTS**

- Edge TTS 音色加印式：`en-IN-PrabhatNeural`（男）/ `en-IN-NeerjaNeural`（女），默认取其一。语气不强制。

**双生图**

- 复用 moretokens chat-SSE-base64 生图机制（参考现 `generate_thumbnail`），但 flow3 内独立实现，分别用模糊底图 Agent / 尾图 Agent 的 prompt，产出两张不同用途的图。底图高斯模糊可在生图 prompt 里要求，或合成时用 ffmpeg `boxblur` 兜底（开发时二选一）。

**ffmpeg 关键命令（供参考）**

- SegC 微动：`zoompan=z='min(zoom+0.0005,1.1)':d=<帧数>:s=1920x1080,fps=30`
- 防封微调：`eq=brightness=0.01:contrast=1.02,scale=iw*1.01:ih*1.01,crop=1920:1080`
- 三段 concat：各段先 scale+pad+fps 统一再 concat（参考现 `merge_clips`，但 flow3 独立实现）。

## 10. 开放问题 / 待确认（评估用）

以下为开发前建议再确认项，不影响主体评审：

1. **基础 AI 工具依赖**：flow3 是依赖 `keywords.services` 的 3 个底层函数，还是彻底复制一份到 flow3？（彻底复制 = 零跨 app 依赖，更干净但有重复代码。）
2. **高斯模糊实现位置**：底图在「生图 prompt 里要求模糊」还是「合成时 ffmpeg boxblur」？后者更可控。
3. **SegB 时长上限保护**：当旁白过长导致 7+SegB > 总时长时，是报错还是自动截断旁白？当前文档设为「报错提示」。
4. **防封微调幅度**：首版用亮度 +0.01 / 对比度 ×1.02 / 缩放 ×1.01，是否可接受？
5. **Hook mp4 规格校验**：是否校验时长=7s、宽高比=16:9？还是只校验格式？

## 11. 与原始 Notion 文档的差异修正记录
