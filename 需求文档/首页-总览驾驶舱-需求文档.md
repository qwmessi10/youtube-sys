# 首页（总览驾驶舱）— 需求文档

> 版本：v1.0
> 创建日期：2026-11-04
> 所属系统：youtube-sys
> 关联：覆盖关键词系统、内容生成(flow3)、AdsPower 自动化(uploader)、SMM 面板、实用工具

---

## 一、背景与目标

系统已有 5 个功能模块（关键词 / 内容生成 / AdsPower / SMM 面板 / 实用工具），运营需要一个首页，一进来就能看到全局状态。

**定位：总览驾驶舱**——纯查看、不跳转、不做待办、不做操作。所有可交互内容都留在各子模块里。

---

## 二、关键决策（已拍板）

| # | 议题 | 决策 |
|---|------|------|
| 1 | 定位 | 总览驾驶舱，**只查看、不跳转** |
| 2 | 待办事项 | **不做** |
| 3 | 指标卡 | 4 个，不变（余额 / 今日出片 / 待核对草稿 / 进行中任务） |
| 4 | 最近动态 | 覆盖**所有系统**，显示**最近 10 条** |
| 5 | 菜单位置 | 「首页」为一级菜单项（无二级），放最顶部 |
| 6 | 数据口径 | 后端一个聚合接口返回，前端不发 N 个请求 |

---

## 三、功能需求

### 3.1 顶部指标卡（4 个）

| 指标 | 口径 |
|------|------|
| SMM 余额（剩余可用） | 所有 SMMAccount 的 `locked_remaining`（余额 − 锁定）之和 |
| 今日出片 | flow3 `Flow3Run` 状态 completed 且 updated_at 为今天 的数量 |
| 待核对草稿 | uploader `UploadTask` 状态 `draft_saved` 的数量 |
| 进行中任务 | 各系统「进行中」状态的任务总数（见 3.2 口径汇总） |

### 3.2 系统概况（5 张卡）

每张卡展示该系统的关键统计，点击**不跳转**（纯展示）：

| 系统 | 统计项 |
|------|--------|
| 关键词系统 | 任务总数 / 进行中(pending+running) / 已完成 / 失败 |
| 内容生成 | 任务总数 / 进行中(running) / 待传 Hook(awaiting_hook) / 已完成 / 失败 |
| AdsPower | 任务总数 / 进行中(queued+launching+uploading) / 草稿待核对(draft_saved) / 失败 |
| SMM 面板 | 账号数 / 刷量任务进行中(pending+running) / 轮询运行中 / 失败 |
| 实用工具 | 拓展任务总数 / 进行中 / 已完成 |

### 3.3 最近动态（时间线，最近 10 条）

合并 5 个系统的最近记录，按时间倒序取前 10 条。每条展示：

- 系统标签（关键词 / 内容生成 / AdsPower / SMM / 工具）
- 类型标签（如「刷量任务」「视频生成」「上传草稿」「长尾词拓展」）
- 标题 / 标识（关键词、视频名、任务号等）
- 状态（进行中 / 已完成 / 失败等）
- 时间

数据来源：`KeywordRun` / `SuggestExpansionRun`（工具）、`Flow3Run`、`UploadTask`、`SMMTask` + `SMMPollTask`。

## 四、实现逻辑

### 4.1 后端聚合接口

新增 `GET /api/dashboard/summary/`，一次性返回首页全部数据：

```json
{
  "metrics": {
    "smm_remaining": 2913.0,   // 锁定后剩余余额合计
    "today_videos": 12,        // 今日出片
    "draft_count": 3,          // 待核对草稿
    "running_count": 5         // 进行中任务合计
  },
  "systems": [
    {"key": "keywords", "name": "关键词系统", "total": 45, "running": 2, "completed": 40, "failed": 3},
    {"key": "flow3", "name": "内容生成", "total": 120, "running": 5, "awaiting_hook": 2, "completed": 110, "failed": 3},
    {"key": "uploader", "name": "AdsPower", "total": 60, "running": 1, "draft": 3, "failed": 1},
    {"key": "smm", "name": "SMM 面板", "accounts": 1, "tasks_running": 50, "polls_running": 2, "failed": 0},
    {"key": "suggest", "name": "实用工具", "total": 30, "running": 1, "completed": 28}
  ],
  "recent": [
    {"system": "smm", "type": "刷量任务", "title": "YTSEO4775", "status": "completed", "time": "..."}
  ]
}
```

实现：用 Django ORM `aggregate` / `count` / `filter` 对各模型按状态统计；`recent` 从 5 个模型各取最近若干条后合并排序截取 10 条。所有查询走一次请求。

### 4.2 前端

- 新增 `frontend/src/components/HomePage.vue`。
- `App.vue` 菜单最顶部加「首页」一级项（`el-menu-item index="home"`，无子菜单）。
- 进入首页调用 `/api/dashboard/summary/` 渲染三块：指标卡（4）、系统概况（5）、最近动态（10）。
- UI 复用现有 `el-card` / `el-tag` 风格，与其它系统一致。

---

## 五、明确不做

- 不做待办事项。
- 首页任何卡片/条目都不跳转、不可点击操作。
- 不做图表、不做实时轮询（进入首页拉一次即可；如需刷新可手动刷新页面）。
